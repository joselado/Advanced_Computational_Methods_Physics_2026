\subsection*{Contents and goals}
Let us first recall where we stopped. In Session 3 we did our many-body calculations again,
directly in the fermionic basis and without any restriction to product states, and this worked
well. We recovered the exact charge-density-wave transition of spinless fermions and the
spin-charge separation in the Hubbard model. However, we found the same limitation that we always
find with exact diagonalization, since the Hilbert space grows as $2^L$ for spinless fermions and
as $4^L$ for the Hubbard chain, so for the Hubbard chain we could only reach about half the length
that we could reach for spins. In Session 4 we introduced the solution to this problem, which is
matrix product states, but we only used them for \emph{spin} Hamiltonians. In this session we will
connect the two. We will solve interacting \emph{fermionic} Hamiltonians with tensor networks, for
system sizes of a hundred sites or more. The way we do this is by first mapping them to spin
Hamiltonians with the Jordan-Wigner transformation, and then using all the MPS tools that we
already built. First, we will repeat the spinless and Hubbard results of Session 3 at a size where
the physics is clear. Then we will introduce two new diagnostics, which are pairing correlators and
the correlation entropy. At the end we will see the general tensor-network algorithm that we have
been using since Session 4 without looking at how it works.

\subsection{The Jordan-Wigner mapping from spins to fermions}
\label{sec:jw}

\subsubsection{Spin models and fermionic models}
The first question we want to answer is almost a philosophical one. Are spin models and fermionic
models in fact the same thing? At first sight they look like different kinds of objects. A
fermionic Hamiltonian is built from operators $\cre{i},\ann{i}$ that anticommute on different
sites, $\{\ann{i},\cre{j}\}=\delta_{ij}$, while a spin-$\tfrac12$ Hamiltonian is built from
operators $S_i^x,S_i^y,S_i^z$ that \emph{commute} on different sites and only have a nontrivial
algebra on the same site. Tensor networks, in the way we built them in Session 4, are bosonic
objects, since an MPS is a product of matrices, one per site, and nothing in this construction
knows about fermionic minus signs. So if we want to use MPS to solve fermionic Hamiltonians, which
is what we want to do in this session, we first need a dictionary that turns a fermionic
Hamiltonian into an equivalent spin Hamiltonian.

\subsubsection{Matching the local Hilbert spaces}
The first step is easy. A single fermionic site has exactly two states, empty $\ket{0}$ and
occupied $\ket{1}=\cre{}\ket{0}$, because $\cre{}\cre{}=0$ forbids double occupancy. A single
spin-$\tfrac12$ also has exactly two states, $\ket{\dn}$ and $\ket{\up}$. So let us identify
them site by site,
\begin{equation}
  \ket{0} \leftrightarrow \ket{\dn}, \qquad \ket{1} \leftrightarrow \ket{\up},
\end{equation}
and in the same way identify the operators that move between them. The operator $\cre{}$ takes an
empty site to an occupied one, in the same way as $S^+$ takes down to up, so we would like to write
$\cre{}\leftrightarrow S^+$ and $\ann{}\leftrightarrow S^-$. Since $n=\cre{}\ann{}$ is $0$ or $1$
while $S^z$ is $\mp\tfrac12$, we also have
\begin{equation}
  S_i^z = n_i - \tfrac12.
\end{equation}
So far this looks like a clean bijection between the two Hilbert spaces. However, there is a point
that we did not discuss yet, which is that fermionic operators on different sites
\emph{anticommute}, while spin operators on different sites \emph{commute}. This mismatch is not a
technical detail, and it means that the naive identification $S_i^+\stackrel{?}{=}\cre{i}$ cannot
be right as it is. Panel (a) of Figure~\ref{fig:jw-string} shows the matching of the two local
spaces, and the other two panels show the correction that we will now construct.

\subsubsection{The string operator}
Let us see the mismatch explicitly, since it is the reason for this whole section. We take the
naive guess $\widetilde S_i^+ \equiv \cre{i}$, $\widetilde S_j^- \equiv \ann{j}$ for $i\ne j$. Then
\begin{equation}
  \widetilde S_i^+ \widetilde S_j^- = \cre{i}\ann{j}, \qquad
  \widetilde S_j^- \widetilde S_i^+ = \ann{j}\cre{i} = -\cre{i}\ann{j},
\end{equation}
where the last step is the fermionic anticommutation relation for $i\ne j$. So the naive guess
gives two operators that \emph{anticommute}, $\widetilde S_i^+\widetilde S_j^- =
-\widetilde S_j^-\widetilde S_i^+$. Real spin operators on different sites must instead
\emph{commute}, $S_i^+S_j^- = S_j^-S_i^+$, because they belong to independent two-level systems
that are joined with an ordinary tensor product. This is the mismatch between anticommutation and
commutation that we found above, and it means that we need to add something to the naive guess
that fixes the sign.

To fix the sign, we order the sites along the chain, and we define, for every site $i$, the
operator
\begin{equation}
  K_i \equiv \prod_{j<i}\left(1-2n_j\right),
\end{equation}
which is the parity of the number of fermions to the left of site $i$, meaning that $K_i=+1$ if an
even number of sites to the left are occupied and $K_i=-1$ if this number is odd. This operator is
what is called the \textbf{Jordan-Wigner string}. Since $K_i$ is built only from number operators
$n_j=\cre{j}\ann{j}$, which are quadratic in fermionic operators, $K_i$ commutes with any fermionic
operator on a different site, because the two sign changes cancel, even though it looks like a
long and complicated string of anticommuting objects. It is also Hermitian and unitary, $K_i^2=1$.
With this, the correct dictionary is
\begin{equation}
  S_i^+ = \cre{i}K_i, \qquad S_i^- = \ann{i}K_i, \qquad S_i^z = n_i - \tfrac12.
  \label{eq:jw}
\end{equation}
We can check by direct computation, using $K_i^2=1$ and the fact that $K_i$ commutes with
operators on other sites, that Eq.~\eqref{eq:jw} gives exactly the correct spin algebra, which is
$[S_i^\alpha,
S_j^\beta]=0$ for $i\ne j$ and the usual $\mathfrak{su}(2)$ algebra on the same site. So the string
is necessary, and it is the one piece of bookkeeping that gives consistent operator algebras to a
fermionic Hilbert space and to a spin Hilbert space, which are the same vector space.

\subsubsection{Why nearest-neighbor hopping barely notices the string}
\label{sec:nnhop}
This mapping is useful in practice, and not only a mathematical curiosity, because of what happens
for nearest-neighbor terms. Let us take $i<j$ and write the general spin bilinear $S_i^+S_j^-$ in
terms of fermions. We write $K_j = K_i(1-2n_i)\prod_{i<k<j}(1-2n_k)$ and use $K_i^2=1$ together
with the operator identity $\cre{i}(1-2n_i)=\cre{i}$. This identity holds because $\cre{i}n_i=0$,
meaning that we cannot create a particle on a site that is already occupied. A short calculation
then gives
\begin{equation}
  S_i^+S_j^- = \cre{i}\ann{j}\prod_{i<k<j}\left(1-2n_k\right), \qquad i<j.
  \label{eq:jwstring}
\end{equation}
So in general, moving an electron from $j$ to $i$ requires a whole string of $S^z$ operators on
every site in between. However, let us look at the special case $j=i+1$. In this case the product
in Eq.~\eqref{eq:jwstring} runs over an empty range and is equal to $1$, so
\begin{equation}
  S_i^+S_{i+1}^- = \cre{i}\ann{i+1}.
\end{equation}
The string cancels completely. We can check directly, with the same identities, that
$S_{i+1}^-S_i^+$ gives the same operator, which confirms that these two spin operators commute as
they must. So \emph{nearest-neighbor} hopping maps to a local spin term without a string, while
longer-range hopping does not. This is the reason why the Jordan-Wigner transformation works so
well with one-dimensional tensor-network methods for nearest-neighbor models. The models for which
we build MPS Hamiltonians never need the string explicitly, since the string only guarantees the
consistency of the mapping and never enters the Hamiltonian that we give to the solver.

  \caption{The Jordan-Wigner string, and why it usually does not appear. (a) The local Hilbert
    spaces matched site by site. A spinless fermionic site, behind, is either empty or occupied,

\end{figure}

\subsubsection{The practical recipe}
Putting all this together, the scheme that we use for the rest of this session has four steps.
First, we start from an interacting fermionic Hamiltonian. Second, we rewrite it site by site and
bond by bond as an equivalent spin Hamiltonian using Eq.~\eqref{eq:jw}, which for nearest-neighbor
models has no explicit strings. Third, we solve this \emph{artificial} spin Hamiltonian, which does
not look physical, with the MPS tools of Session 4. Fourth, we map the expectation values back to
the fermionic language with the same dictionary in reverse. In practice, once this is set up, we
can think of it as a many-body solver for interacting fermions and forget about the string. This is
what the \texttt{fermionchain} class of \texttt{dmrgpy} does internally for every calculation in
the companion notebook, which uses open boundary conditions everywhere. This matters because the
cancellation of the string for nearest-neighbor hopping in Section~\ref{sec:jw} relies on a fixed
ordering of the sites from left to right. On a periodic chain, the bond that closes the ring is not
nearest-neighbor in this ordering, and it gets an explicit string that depends on the filling,
which is one more reason to use open chains.

For a Hubbard-type model with spin, each site has two fermionic flavors, $\cre{i\up}$ and
$\cre{i\dn}$, so the recipe above needs one more choice. Before we can apply Eq.~\eqref{eq:jw}, we
need an explicit ordering of all the $2L$ orbitals along a single one-dimensional string. The
natural option is to interleave them site by site, $\up_1,\dn_1,\up_2,\dn_2,\ldots$, so that
operators on the same site stay next to each other. The other option is to put all the up spins
first and all the down spins after them, $\up_1,\ldots,\up_L,\dn_1,\ldots,\dn_L$, which keeps the
hopping of each spin sector local but turns the onsite $U$ term into a long string. Both orderings
are exact, and \texttt{dmrgpy} chooses one for us internally, so keep in mind that this choice
exists when you see a spinful Jordan-Wigner string written somewhere else.

\subsection{The spinless interacting chain at large scale}
\label{sec:spinless}

\subsubsection{The model and its two limits}
Let us now use these tools for a model that we already know well from Session 3, which is spinless
fermions with nearest-neighbor hopping and nearest-neighbor repulsion,
\begin{equation}
  \Ham_{\mathrm{CDW}} = -t\sum_i\left(\cre{i}\ann{i+1}+\mathrm{h.c.}\right) + V\sum_i n_in_{i+1}.
  \label{eq:cdw}
\end{equation}
We already know its two limits. At $V=0$ it is a free-fermion metal, and for $V\to\infty$ it
becomes a charge density wave, with one electron on every other site. What exact diagonalization
could not tell us clearly is where between these two limits the transition happens,
because $L\lesssim 16$ is too small to see a sharp thermodynamic phase transition. MPS will answer
this question for us.

\subsubsection{The equivalence with the XXZ chain}
Before the numerics, let us look at the Jordan-Wigner image of Eq.~\eqref{eq:cdw}, because it
connects us again to a model from Session 2. Using Eq.~\eqref{eq:jw} and \eqref{eq:jwstring} for
neighboring sites, the hopping term becomes
$-t(S_i^+S_{i+1}^-+\mathrm{h.c.}) = -2t(S_i^xS_{i+1}^x+S_i^yS_{i+1}^y)$. The density term is
diagonal and easy to translate, $n_in_{i+1} = S_i^zS_{i+1}^z + \tfrac12(S_i^z+S_{i+1}^z) +
\tfrac14$. Summed over the whole chain, the linear term $\tfrac12\sum_i(S_i^z+S_{i+1}^z)$ is equal
to $VS_{\mathrm{tot}}^z$, up to the two boundary sites that do not cancel. This is a uniform field
that commutes with the hopping in the bulk and only shifts the energy at fixed filling, meaning at
fixed $S_{\mathrm{tot}}^z$. The remaining $O(1)$ boundary field on the first and last site does not
commute with the hopping in the bulk, but it is a boundary effect that does not change the
transition in the bulk, so we drop it here, and we are left with
\begin{equation}
  \Ham_{\mathrm{CDW}} \;\longleftrightarrow\;
  \sum_i\left[-2t\left(S_i^xS_{i+1}^x+S_i^yS_{i+1}^y\right) + V S_i^zS_{i+1}^z\right] + \mathrm{const.}
  \label{eq:xxzferm}
\end{equation}
This is the \textbf{XXZ chain} with anisotropy $\Delta \equiv V/(2t)$. Its exact
Bethe-ansatz solution puts the transition between a gapless easy-plane phase and a gapped
N\'eel-ordered phase exactly at the isotropic Heisenberg point $\Delta=1$, which is at $V=2t$. We
should keep this number in mind, since we will find it again numerically. Panel (a) of
Figure~\ref{fig:xxz-pinning} shows the dictionary on a single bond, where the hop of an electron is
the flip-flop of an up and a down spin, and two neighboring electrons are two neighboring up spins.

\subsubsection{Charge order from a pinning field}
A Hamiltonian with translational symmetry cannot spontaneously break this symmetry in a finite
calculation, since the ground state stays a symmetric superposition of the two CDW patterns. For
this reason, here and also in the mean-field discussion of Session 1, we add an infinitesimal seed
that breaks the symmetry, and we see whether the bulk amplifies it or screens it. Let us take a
chain of $L=100$ sites, add a small pinning term that favors a bit less charge on the first site
and a bit more on the last one, and look at the resulting charge profile $\expval{n_i}$.

For strong interaction, $V=40t$, the pinning is enough for the whole chain to lock into the
charge-ordered pattern, with high and low density alternating from one edge to the other. This
tells us clearly that we are inside the symmetry-broken phase. For moderate interaction, $V=t$, the
result is completely different. The charge oscillates near the pinned edge, but the amplitude of
the oscillation decays as we move into the bulk, and in the middle of the chain the density has gone
back to the uniform value $\expval{n_i}=\tfrac12$. In other words, the bulk screens the
perturbation, which is the signature of a phase that does \emph{not} break translational symmetry,
even though $V=t$ is a sizeable interaction. Panel (b) of Figure~\ref{fig:xxz-pinning} shows the
two profiles next to each other.

\subsubsection{The phase transition at $V_c$}
We can make the qualitative picture above quantitative by changing $V$ continuously and following
the bulk charge imbalance as a function of $V$, or equivalently the site density deep in the chain,
far from the pinning. Below a critical value, the bulk density stays flat at
$\expval{n}=\tfrac12$ regardless of how strongly we pin the edges. Above it, the bulk itself
develops a finite charge imbalance, and the pinning field is only needed to select which of the two
equivalent sublattices orders. Numerically this happens at $V_c\approx 2t$, in agreement with the
exact XXZ result that we derived in Eq.~\eqref{eq:xxzferm}. This is a quantum phase transition in
the thermodynamic limit, which is a nonanalyticity of the ground state as a function of $V$ at zero
temperature. Exact diagonalization with the $L\sim12$ to $14$ of Session 3 could not resolve it
sharply, and the transition only becomes sharp at the $L\sim100$ scale that MPS gives us.

\end{notebook}

\subsection{Correlators as a diagnostic of the phases}
\label{sec:correlators}
Pinning fields and density profiles are intuitive, but they need an explicit term that breaks the
symmetry. A cleaner diagnostic, without any field, comes from nonlocal correlation functions, and
it generalizes something that we already used for the Heisenberg model in Session 2.

\subsubsection{The nonlocal particle-particle correlator}
We define the single-particle correlator between the first site and site $n$,
\begin{equation}
  C(n) \equiv \expval{\cre{1}\ann{n}}.
\end{equation}
Physically, this is what a Kubo-formula response calculation would give if we pinned site $1$ with
an infinitesimal field and measured the induced amplitude at site $n$. So it contains the same
physics as the pinning-field experiment of Section~\ref{sec:spinless}, but in a single object
without any field. In a gapless metallic phase, $C(n)$ decays only as a power law,
$C(n)\sim n^{-\alpha}$, because there are excitations at arbitrarily low energy that keep
correlations alive at arbitrarily long distance. This is the same phenomenology that we found for
the gapless quantum magnet in Session 2. In a gapped insulating phase, on the other hand, $C(n)$
decays exponentially,
\begin{equation}
  C(n) \sim e^{-n/\xi},
\end{equation}
where $\xi$ is the \textbf{correlation length}, which is set by the energy gap. A finite energy is
needed to create an excitation, and this finite energy cost is what kills correlations beyond a
finite distance.

For the model of Eq.~\eqref{eq:cdw}, both $V=0$ and $V=t$ give a power-law decay, which is a
straight line on a log-log plot, while $V=6t$, deep in the charge-ordered phase, gives instead a
straight line on a \emph{log-linear} plot, meaning an exponential decay. This is the same contrast
between the $V=0/1$ metal and the $V=6$ insulator that we already expected qualitatively in
Section~\ref{sec:spinless}, and now it is completely quantitative.

\begin{notebook}
Section ``Non-local static correlators for the particle-particle response of a large interacting
fermionic model.'' Plot $\ln\abs{C(n)}$ against $n$ for a few values of $V$, and confirm that the
metal gives a slowly varying curve, which is a power law, while the CDW gives a straight line,
which is an exponential decay with slope $-1/\xi$.
\end{notebook}

\subsubsection{Pairing correlators and the Cooper-pair susceptibility}
Everything so far involved moving a single electron. Let us now ask a different question, which is
how much the ground state wants to create or destroy a \emph{pair} of electrons at the same time.
We define the local bond-pair annihilation operator $\Delta_i \equiv \ann{i}\ann{i+1}$ and its
correlator,
\begin{equation}
  P(i,j) \equiv \expval{\Delta_j^{\dagger}\Delta_i}
    = \expval{\cre{j+1}\cre{j}\,\ann{i+1}\ann{i}}.
\end{equation}
This is a new object, with no analogue in Session 3, where we never asked two-particle questions of
this kind. It is a four-point correlator, also called a two-particle correlator, and it measures how
correlated the destruction of a pair near $i$ is with the creation of a pair near $j$. By the same
Kubo-formula argument as before, it is what determines the linear response of the system to
an external pairing field, which is what is called its \textbf{Cooper-pair susceptibility}.

For the repulsive model of Eq.~\eqref{eq:cdw}, $P(i,j)$ decays faster than in the noninteracting
case. Repulsion discourages two electrons from being close to each other, so it \emph{quenches}
pairing fluctuations. If instead we change the sign of the interaction and make it attractive,
$V<0$, the correlator decays more slowly than in the noninteracting case, meaning that the system is
more willing to host a fluctuating pair. This is the microscopic seed of Cooper pairing and
superconductivity, which is the same attractive channel that we mentioned in Session 1 but did not
study further. So repulsive interactions suppress pair correlations, and attractive interactions
enhance them.

\begin{notebook}
Section ``Non-local pairing fluctuations of an attractive fermionic model.'' Compare $P(i,j)$ for
$V=0$, a repulsive $V>0$ and an attractive $V<0$, and confirm that repulsion makes the pairing
correlator decay faster than in the free case, while attraction makes it decay slower.
\end{notebook}

\subsection{Spin-charge separation in the Hubbard model at large scale}
\label{sec:hubbard}

\subsubsection{The Hubbard chain and its two kinds of excitations}
Let us now include spin again and go back to the Hubbard model,
\begin{equation}
  \Ham_{\mathrm{Hub}} = -t\sum_{i\sigma}\left(\cre{i\sigma}\ann{i+1,\sigma}+\mathrm{h.c.}\right)
    + U\sum_i n_{i\up}n_{i\dn}.
\end{equation}
In Session 3 we already saw, with exact diagonalization on small chains, that at strong $U$ this
model shows \textbf{spin-charge separation}. The individual electron cannot be split, but the
collective low-energy excitations of the many-body ground state can. Charge excitations are gapped,
since it costs a finite energy $\sim U$ to move a charge across the Mott-insulating background.
Spin excitations are instead gapless, because at half filling and strong $U$ the Hubbard model maps
to the Heisenberg antiferromagnet of the superexchange derivation of Session 1, and the Heisenberg
model is a gapless quantum magnet with fractional spin-$\tfrac12$ spinon excitations, as we studied
directly in Session 2. What large system sizes give us here is that we can see this contrast not as
a hint in a few energy levels, but as two very different decay laws in real space.

\subsubsection{Charge gap from the particle-particle correlator}
As in Section~\ref{sec:correlators}, we follow $C(n) = \expval{\cre{1\sigma}\ann{n\sigma}}$.
At $U=0$ the chain is a free-fermion metal and $C(n)$ decays as a slow power law. When we turn on
$U$, the decay becomes faster and faster, and once $U$ is large enough to open the Mott gap, $C(n)$
decays exponentially, with a correlation length that becomes shorter as $U$ grows. This is the
signature of the charge gap that we are looking for.

\begin{notebook}
Section ``Non-local static correlators for the particle-particle response of a large Hubbard
model'' and, next to it, ``Spin and charge correlator in the Hubbard model.'' Plot
$\ln\abs{C(n)}$ for increasing $U$ and confirm the crossover from power-law to exponential decay,
which is the charge gap seen in real space.
\end{notebook}

\subsubsection{Gapless spin excitations from the spin-spin correlator}
Let us now build the analogous correlator for spin instead of charge, $\expval{\vb S_1\cdot\vb S_n}$.
Since $S_i^z = \tfrac12(n_{i\up}-n_{i\dn})$ and $S_i^+=\cre{i\up}\ann{i\dn}$, this is a
\emph{biquadratic} object in the fermionic operators, meaning a product of two fermion bilinears
rather than a single one, but it is computed in the same way once it is written in the underlying
MPS. The result is the mirror image of the charge correlator. At $U=0$ the spin correlator decays
quickly, but as $U$ grows it becomes \emph{more} long-ranged, which is the opposite trend to the
charge correlator. This is spin-charge separation written as two decay rates. Repulsion opens a gap
in the charge sector while it keeps, and even enhances, the spin correlations, which is consistent
with the mapping to a gapless Heisenberg spin chain at strong $U$.

\begin{notebook}
Section ``Spin-Spin non-local correlator of the Hubbard model.'' Plot $\ln\abs{\expval{\vb
S_1\cdot\vb S_n}}$ for increasing $U$ and confirm the opposite trend to the charge correlator,
which is that the decay gets \emph{slower} as $U$ grows. Try also an attractive $U$, and think about
why the roles of the spin and charge sectors should be exchanged in that case.
\end{notebook}

\subsubsection{Pairing correlators in the Hubbard model}
Finally, we define the onsite singlet pair operator $\Delta_i^{\mathrm{onsite}} \equiv
\ann{i\dn}\ann{i\up}$, which is a different pairing channel from the nearest-neighbor bond operator
$\Delta_i$ of Section~\ref{sec:correlators}, and its correlator
$\expval{(\Delta_j^{\mathrm{onsite}})^{\dagger}\Delta_i^{\mathrm{onsite}}}$. This is the direct
analogue for the Hubbard model of the pairing susceptibility that we built in
Section~\ref{sec:correlators}. The qualitative conclusion is the same as before, since repulsive
$U$ suppresses the pairing correlator with respect to the noninteracting case, while attractive $U$
enhances it. With the two Hubbard results of this section, we have now seen the full statement that
we announced at the beginning of the section. Repulsion opens a gap in the charge sector, leaves the
spin sector gapless or even enhances it, and at the same time quenches pairing, which is the opposite of what an attractive interaction would do.

\subsection{The correlation entropy and the validity of mean-field theory}
\label{sec:corrent}

\subsubsection{The need for a many-body description}
In Sessions 4 and 5 we have assumed, without saying it, that we \emph{need} the full many-body
machinery and that mean-field theory is never enough. But is this always true? We now have a tool
that answers this question directly from the exact ground state, without running a separate
mean-field calculation and comparing energies by hand.

\subsubsection{Definition via the correlation matrix}
Let us take the same nonlocal correlator that we have used during the whole session,
$C_{ij} \equiv
\expval{\cre{i}\ann{j}}$, but now we do not look at it as a single number for fixed $i=1$. Instead,
we look at it as an $L\times L$ Hermitian matrix, which is called the \textbf{correlation matrix}.
We diagonalize it, $C = \sum_k \nu_k \ket{k}\bra{k}$, with real eigenvalues $\nu_k$.

Let us first assume that the ground state is a Slater determinant, $\ket{\Psi} = \prod_{n\in\mathrm{occ}}
\cre{a_n}\vac$, which is the kind of state that mean-field theory builds. In the single-particle
basis that diagonalizes the mean-field orbitals, $C_{ij}$ is diagonal, with a $1$ for every occupied
orbital and a $0$ for every empty one, so $C^2=C$. This means that the correlation matrix of a
Slater determinant is a \emph{projector}, and a projector has eigenvalues that are exactly $0$ or
$1$, since $\nu_k^2=\nu_k$ forces $\nu_k\in\{0,1\}$. This gives us a clean test. If every eigenvalue
of $C$ is exactly $0$ or $1$, the state is a single Slater determinant, or is equivalent to one, and
mean-field theory can reach it exactly.

For a correlated ground state, $C^2\ne C$ in general, and the eigenvalues $\nu_k$ are spread
continuously over $[0,1]$ instead of sitting at the two endpoints. We can quantify how far we are
from the product-state limit with an entropy that is built in the same way as a binary Shannon
entropy for each occupation probability $\nu_k$,
\begin{equation}
  S_{\mathrm{corr}} = -\sum_k \Big[\nu_k\ln\nu_k + (1-\nu_k)\ln(1-\nu_k)\Big].
  \label{eq:corrent}
\end{equation}
Every term in the sum vanishes when $\nu_k\in\{0,1\}$ and is strictly positive otherwise, so
$S_{\mathrm{corr}}=0$ if and only if the ground state is exactly a Slater determinant. The larger
$S_{\mathrm{corr}}$ is, the further the true ground state is from anything that a single mean-field
calculation could produce, regardless of how it was initialized. Figure~\ref{fig:corr-entropy}
shows the eigenvalues $\nu_k$ as the fillings of cups, for a Slater determinant and for a
correlated ground state.

\begin{figure}[H]
  \centering
  \includegraphics[width=\textwidth]{figures/mps_fermionic/corr_entropy.pdf}
  \caption{The eigenvalues of the correlation matrix, with one cup per natural orbital $\ket{k}$
    filled to $\nu_k$. (a) A Slater determinant, which is the four-site Hubbard chain of the
    notebook at $U=0$ and half filling. Every cup is full or empty, so every term of
    Eq.~\eqref{eq:corrent} vanishes and $S_{\mathrm{corr}}=0$. (b) The same chain at $U=6t$, from
    exact diagonalization. The eight eigenvalues come in spin pairs, $0.82$, $0.73$, $0.27$ and
    $0.18$, no cup is full or empty, and $S_{\mathrm{corr}}=4.22$, meaning that no single Slater
    determinant reproduces this ground state. What $S_{\mathrm{corr}}$ measures is how far the cups
    are from being full or empty.}
  \label{fig:corr-entropy}
\end{figure}

\subsubsection{Applied to the spinless chain}
Let us apply Eq.~\eqref{eq:corrent} to the model of Eq.~\eqref{eq:cdw}. We already know that both of
its limits are in fact product states. At $V=0$ the ground state is the filled Fermi sea, which is a
Slater determinant by construction. At $V\to\infty$ the ground state is the perfect
charge-density-wave pattern, with one electron on a site, none on the next one and so on, which is
also exactly a single Slater determinant, only in real space instead of momentum space. So
$S_{\mathrm{corr}}
\to 0$ at both ends. In between, and in particular close to the critical point $V\approx 2t$ that
we found in Section~\ref{sec:spinless}, the correlation entropy has a clear peak. This is the
regime where the ground state is most entangled and furthest from a description with a single
Slater determinant, and it coincides with the quantum phase transition itself, since critical
points are in general where correlations, and therefore entanglement, are strongest.

\subsubsection{Driving a quantum magnet toward its mean-field solution}
We can make this diagnostic even more concrete by building, in a single Hamiltonian, a controlled
crossover between a strongly correlated state and a mean-field one. Let us take the Hubbard model
and add exactly the staggered mean-field magnetic term that the self-consistent loop of Session 1
would have generated by itself, which is the same staggered field that we switched on in Session 3,
\begin{equation}
  \Ham = \Ham_{\mathrm{Hub}} + J_z\sum_i (-1)^i S_i^z.
\end{equation}
At $J_z=0$ this is the ordinary Hubbard model, which at strong $U$ and half filling behaves like a
gapless quantum antiferromagnet. This state is similar to a spin liquid, in the sense that the
local magnetization vanishes everywhere by symmetry, even though the spin-spin correlations are
long-ranged. When we turn on $J_z$, we explicitly push the ground state toward the symmetry-broken
state with staggered magnetization that mean-field theory would give us directly. And indeed, as
$J_z$ grows, the correlation entropy of Eq.~\eqref{eq:corrent} decreases systematically. The ground
state is pushed by hand toward the kind of product-like, symmetry-broken state to which a
self-consistent mean-field calculation would converge by itself. This brings us back to Session 1.
In Session 3 we saw the magnetization grow with this same field, and now we can also see
quantitatively how much entanglement is lost in the product-state simplification that mean-field
theory always makes, and so when it is a good approximation and when it is not.

stronger $U$ should push the system further from a mean-field description, or closer to it.

\subsection{The general tensor-network algorithm}
\label{sec:algorithm}
We have now used matrix product states a lot, during two full sessions, without looking at how the
ground-state search is actually done. Let us finish by doing this.

\subsubsection{Diagrammatic notation}
It helps a lot to draw tensors instead of writing out their indices. A scalar is a dot with no
legs, a vector is a dot with one leg, a matrix is a dot with two legs, and a general rank-three
tensor is a dot with three legs, with one leg per index. Contracting an index between two tensors,
meaning summing over it, is drawn by joining the corresponding legs into a single line. For
instance, a matrix-vector multiplication is a dot with two legs joined to a dot with one leg along
one shared leg, which leaves one free leg, so the result is a vector again, as it should be. An MPS
is then a one-dimensional chain of such dots. Each site has one \emph{physical} leg, of dimension
$2$ for a spin-$\tfrac12$ or, after Jordan-Wigner, for a spinless-fermion site, and two
\emph{bond} legs of dimension $\chi$ that connect it to its left and right neighbors,
\begin{equation}
  \ket{\Psi} = \sum_{\{s_i\}} M_1^{s_1}M_2^{s_2}\cdots M_L^{s_L}\,
    \ket{s_1s_2\cdots s_L},
\end{equation}
where each $M_i^{s_i}$ is a $\chi\times\chi$ matrix, with a row and a column vector at the two
ends, and the matrix product along the chain is exactly the string of joined bond legs in the
diagram. The bond legs have no physical meaning by themselves. They are the bookkeeping that allows
a single tensor to encode the entanglement between the two halves of the chain that it separates,
with the bound $S_A\le\ln\chi$, which is the entanglement-entropy bound that we derived in
Session 4.

\begin{figure}[H]
  \centering
  \includegraphics[width=\textwidth]{figures/mps_fermionic/tensor_notation.pdf}
  \caption{Diagrammatic notation for tensors, and the matrix product operator. (a) A dot with one
    leg per index. A scalar $s$ has no legs, a vector $v_i$ has one, a matrix $A_{ij}$ has two and a
    rank-three tensor $T_{ijk}$ has three. Summing over an index shared by two tensors is drawn by
    joining the corresponding legs, here the leg $j$ of a matrix and of a vector, so what is left
    has one free leg and is a vector again, exactly as it should be for a matrix-vector
    multiplication. (b) A matrix product operator, which is the operator version of the matrix
    product state that we used in Session 4. Each site tensor $W_i^{s_is_i'}$ has two physical
    legs, one up for the row index $s_i$ and one down for the column index $s_i'$, in addition to
    the two internal bond legs, here of dimension $\chi_W$, and the tensors at the ends have a
    single bond leg. For a nearest-neighbor Hamiltonian these internal bonds only need to carry a
    few states, which is enough to encode $\Ham$ exactly and not approximately.}
  \label{fig:tensor-notation}
\end{figure}

\subsubsection{Matrix product operators}
Hamiltonians need the same treatment. A \textbf{matrix product operator (MPO)} is the operator
version of an MPS. Instead of one physical leg per site we now have two, one for the row index and
one for the column index of the local operator, together with the same two internal bond legs as
before,
\begin{equation}
  \Ham = \sum_{\{s_i,s_i'\}} W_1^{s_1s_1'}W_2^{s_2s_2'}\cdots
    W_L^{s_Ls_L'}\,\ket{s_1\cdots s_L}\bra{s_1'\cdots s_L'}.
\end{equation}
For a nearest-neighbor Hamiltonian such as $\Ham_{\mathrm{Heis}} = J\sum_i \vb S_i\cdot\vb S_{i+1}$,
this internal bond dimension, which we call $\chi_W$, can be made very small. It only needs to be
large enough to store whether nothing has happened yet, whether an $S^x$, $S^y$ or $S^z$ was just
placed and waits for its partner on the next site, or whether the interaction has already been
closed. So a few internal states per bond are enough to represent the exact Hamiltonian, and not an
approximation to it. Panel (b) of Figure~\ref{fig:tensor-notation} shows this chain of operator
tensors.

\subsubsection{Contraction and compression when applying $\Ham$ to a state}
The operation that we need again and again is $\Ham\ket{\Psi}$. In diagrams, this means joining the
physical legs of the MPO to the physical legs of the MPS, one site at a time, and merging the two
bond legs that now run in parallel between neighboring sites, one from the MPS and one from the
MPO, into a single wider bond. The result is again an MPS, but with bond dimension $\chi\chi_W$,
which is the product of the two bond dimensions that we started with. This is the practical cost of
contraction. Every time we act with $\Ham$, the bond dimension grows, and if we did this many times
without doing anything else, it would grow exponentially and we would lose the whole advantage of
using an MPS. The solution is the same tool that we already used for state compression in
Session 4, which is a singular value decomposition on every bond, where we keep only the largest
$\chi$ singular values and discard the rest. This is equivalent to keeping the $\chi$ largest
eigenvalues of the reduced density matrix across that bond. Because the entanglement in a gapped
one-dimensional system saturates at a finite value, this truncation introduces only a small and
controllable error, and it is the most important practical operation behind every tensor-network
calculation that we have run in this session.

\subsubsection{The DMRG sweep as a variational search}
Finally, how do we actually find the ground state, and not only apply $\Ham$ once? We treat the MPS
as a variational ansatz and minimize the energy functional directly. We introduce a Lagrange
multiplier $\lambda$ to enforce normalization, so we want a stationary point of
\begin{equation}
  f[\{M\}] = \bra{\Psi[\{M\}]}\Ham\ket{\Psi[\{M\}]} - \lambda\left(\braket{\Psi[\{M\}]}-1\right).
\end{equation}
The key simplification, and the reason why this problem can be solved at all, is that $\ket{\Psi}$
is \emph{linear} in any single one of its tensors $M_i^{s_i}$ once all the others are fixed. We set
$\partial f/\partial M_i^{s_i} = 0$ at fixed neighbors and contract all the tensors that we are not
currently changing, on both the bra and the ket side, together with the Hamiltonian MPO. This
reduces the whole exponentially large problem to a small effective eigenvalue equation that lives
only on the local space at site $i$, which is the product of the physical space and the two bond
spaces,
\begin{equation}
  H_{\mathrm{eff}}(i)\, M_i^{s_i} = \lambda\, M_i^{s_i}.
\end{equation}
We diagonalize this small dense matrix, whose size is set by $\chi$ and not by the full
$2^L$-dimensional Hilbert space, and we keep the lowest eigenvector as the new $M_i^{s_i}$. Then we
move to site $i+1$, build its effective Hamiltonian again with the tensor at $i$ that we just
updated, and repeat. We sweep all the way to the right end of the chain and back to the left, and
we repeat this sweep until the energy stops changing. This procedure is the \textbf{density matrix renormalization group (DMRG)} algorithm. In this sense, variational MPS
optimization and DMRG are the same procedure, reached from two different starting points.

  \centering
  \includegraphics[width=\textwidth]{figures/mps_fermionic/mps_algorithm.pdf}
  \caption{The two operations from which every calculation in these two sessions is built, with the
    tensors of the state in teal and those of the operator in violet. (a) Acting with $\Ham$, drawn
    by joining the column legs of the matrix product operator to the physical legs of the state one
    site at a time, with the legs of the state drawn pointing up so that the two chains stack. The
    two bond legs that now run in parallel, of dimensions $\chi$ and $\chi_W$, merge into a single
    one of dimension $\chi\chi_W$, drawn thick. So the result is again a matrix product state, only
    with a larger bond dimension, and a singular value decomposition on every bond that keeps the
    largest $\chi$ values compresses it back. (b) The variational ground-state search. The state,
    the operator and the conjugate state are stacked, and everything except site $i$ is contracted
    into a left and a right environment, which are the shaded blocks. The tensors of the state and
    of its conjugate at $i$ are left out, so what remains is $H_{\mathrm{eff}}(i)$ with the open
    legs on which $M_i^{s_i}$ sits. This reduces the exponentially large problem to the small
    eigenvalue problem $H_{\mathrm{eff}}(i)M_i^{s_i}=\lambda M_i^{s_i}$ at that one site. Solving
    it, moving one site over and repeating, back and forth along the chain, is the DMRG sweep.}
  \label{fig:mps-algorithm}
\end{figure}

\subsubsection{PEPS and MERA beyond matrix product states}
Matrix product states are the simplest tensor-network architecture, with one tensor per site along
a line, and this simplicity is the reason why they work so well in one dimension. The entanglement
across any cut of a gapped 1D chain saturates, so a finite bond dimension is enough. The natural
generalization to two dimensions is a \textbf{projected entangled pair state (PEPS)}, which gives
every site one bond leg per lattice neighbor instead of only two. This allows it to capture the
larger area-law entanglement of 2D systems, but there is a price, since we lose the cheap and exact
contraction that we used during the whole session. Contracting a 2D tensor network exactly is
computationally hard in general, and PEPS calculations rely on additional approximate contraction
schemes. Critical, scale-invariant 1D systems give a related problem even in one dimension, since
their entanglement grows logarithmically with subsystem size instead of saturating. This is the
regime for which the \textbf{multiscale entanglement renormalization ansatz (MERA)} was built,
which is a hierarchical network of alternating disentangling and coarse-graining tensors, organized
in layers that follow the scale invariance of the critical point itself. We will not develop either
of these further in this course, but it is useful to know that they exist. MPS is the first and
most tractable member of a much larger family of variational tensor architectures, where each
member gives more entanglement capacity at the cost of a harder optimization problem.

\subsection*{Closing summary}
\begin{itemize}[nosep]
  \item The Jordan-Wigner mapping identifies the fermionic and spin-$\tfrac12$ local Hilbert spaces
    site by site, and fixes the resulting mismatch between anticommutation and commutation with a
    string operator $K_i$. Nearest-neighbor fermionic hopping maps to a spin term without a string,
    which is the reason why MPS methods for 1D nearest-neighbor models fit fermionic chains so
    naturally.
  \item Mapping the fermionic Hamiltonian to its Jordan-Wigner spin image and solving it with MPS
    allows us to repeat the spinless CDW transition and the Hubbard spin-charge separation of
    Session 3 at $L\sim100$. At this size the results are sharp and clear, and they are not blurred
    by the limit of exact diagonalization, which is $L\sim20$ for spinless fermions and half of that
    for the Hubbard chain. The transition of the spinless chain at $V_c\approx2t$ matches the exact
    XXZ result.
  \item Nonlocal particle-particle correlators distinguish gapless phases, with a power-law decay,
    from gapped phases, with an exponential decay. Pairing correlators, which are a new four-point
    diagnostic, show that repulsive interactions quench Cooper-pair fluctuations while attractive
    interactions enhance them, in both the spinless and the Hubbard models.
  \item The correlation matrix built from these correlators has eigenvalues in $[0,1]$, which are
    exactly $0$ or $1$ only for a Slater determinant. The resulting correlation entropy measures
    how far a ground state is from any mean-field description. It has a peak at the phase
    transition of the spinless chain, and it decreases smoothly as a staggered field drives the
    Hubbard model toward its mean-field, symmetry-broken solution.
  \item The general tensor-network algorithm represents states as MPS and operators as MPOs.
    Applying $\Ham$ makes the bond dimension grow, and this growth is controlled by a truncation
    based on the SVD. The variational ground-state search reduces, tensor by tensor, to a sequence
    of small effective eigenvalue problems that are solved by sweeping back and forth along the
    chain, which is the DMRG algorithm. PEPS and MERA extend the same idea to two dimensions
    and to critical systems, respectively, and they are beyond the scope of this course.
  \item Looking back at the whole course, mean-field theory, in Session 1, gives us a cheap
    approximation with polynomial cost that can fail qualitatively whenever the true ground state is
    entangled. Exact diagonalization, in Sessions 2 and 3, removes this failure completely but only
    for small systems, since the Hilbert space grows exponentially. Matrix product states, in
    Sessions 4 and 5, recover the exact many-body answer, including the entanglement, at the large
    system sizes that are meaningful for the thermodynamic limit. At these sizes the physics, such
    as phase transitions, fractionalization and spin-charge separation, becomes clear, and the cost
    stays polynomial as long as the entanglement stays bounded. This progression, from product
    states, to unrestricted but very small Hilbert spaces, to states with bounded entanglement at
    large sizes, is the main idea that connects the whole course.
\end{itemize}
