\subsection*{Contents and goals}
In this session we build the minimal tools that we need to describe interacting electrons, which
is second quantization, and we use them to answer a concrete question. The question is when
repulsive electron--electron interactions spontaneously break a symmetry of the Hamiltonian. We
will look at two symmetry-broken phases, classical magnetism and charge density waves, and we
will treat both of them at the mean-field level. At the end of the session we will see a case
where we can show that mean-field theory gives the wrong ground state, which is the Hubbard
dimer, and this failure is the reason why we develop exact-diagonalization and tensor-network
methods in the rest of the course.

\subsection*{Learning outcomes}
By the end of this session, you should be able to do the following.
\begin{itemize}[nosep]
  \item Write single-particle and many-body Hamiltonians in second-quantized form, and explain
    why the interaction term makes the many-body problem exponentially hard.
  \item Set up and run a mean-field self-consistency loop for the Hubbard and CDW models, and
    interpret the resulting exchange splitting, gap and order parameter.
  \item Derive the superexchange coupling $J\sim t^2/U$ from degenerate perturbation theory and
    use it to predict collinear versus frustrated classical spin order.
  \item Identify when mean-field theory fails qualitatively, and explain why, using the
    entangled singlet ground state of the Hubbard dimer as the counterexample.
\end{itemize}

\subsection{Single-particle versus many-body Hamiltonians}
\subsubsection{Single-particle Hamiltonians}
Let us start by separating electronic Hamiltonians into two broad classes. The first class
contains the Hamiltonians that are bilinear in the field operators, which we call single-particle
Hamiltonians,
\begin{equation}
  \Ham_0 = \sum_{ij} t_{ij}\, \cre{i}\ann{j},
\end{equation}
where $t_{ij}$ is a hopping amplitude, and we can think of it as the probability amplitude for an
electron in orbital $j$ to jump to orbital $i$. Since $\Ham_0$ is only a matrix acting on a
single-particle Hilbert space, every electron here moves essentially independently of the
others, and to find the spectrum we only need to diagonalize an $L\times L$ matrix for
$L$ orbitals. This is already enough to describe many materials, such as insulators,
semiconductors and ordinary metals.

\subsubsection{The quartic interaction term}
The case we care about most is the many-body case. Here we again have the bilinear term, but we
also add a term that is quartic in the fermionic operators,
\begin{equation}
  \Ham = \Ham_0 + \sum_{ijkl} V_{ijkl}\, \cre{i}\cre{j}\ann{k}\ann{l},
  \label{eq:generalH}
\end{equation}
and $V_{ijkl}$ gives the strength of this interaction. This term is responsible for essentially
all of the exotic phenomena we are interested in for quantum materials, such as magnetism,
charge density waves, superconductivity and every strongly correlated phase we will see later
in the course. Second quantization is useful because it allows us to write both the
single-particle and the many-body part of Eq.~\eqref{eq:generalH} in the same language.

\subsubsection{The size of the many-body problem}
The price of the quartic term is the size of the space where it acts. One electron on $L$
orbitals has $L$ states, so $\Ham_0$ is an $L\times L$ matrix. In contrast, any number of
electrons on the same $L$ orbitals has $2^L$ occupation configurations, since each orbital is
either empty or occupied, and the interacting $\Ham$ is a $2^L\times 2^L$ matrix.
Figure~\ref{fig:exponential-wall} counts both, first for a chain of four sites and then as $L$
grows.

\subsection{Second quantization}
\subsubsection{Creation and annihilation operators}
So let us set up this language. We define the fermionic annihilation and creation operators
$\ann{i}$, $\cre{i}$ for orbital $i$, and a vacuum state $\vac$ that has no electrons, so that
$\ann{i}\vac = 0$ for every $i$. We can think of the vacuum as a vector and of the operators as
matrices that map one vector to another. A single-particle basis state is then $\cre{i}\vac$,
and the matrix elements of $\Ham_0$ in this basis are the hopping amplitudes $t_{ij}$ we started
with.

\subsubsection{Anticommutation and local degrees of freedom}
How do we enforce mathematically that no site can hold more than one electron of a given
species? We impose the canonical anticommutation relations,
\begin{equation}
  \{\ann{i},\cre{j}\} = \delta_{ij}, \qquad \{\ann{i},\ann{j}\} = \{\cre{i},\cre{j}\} = 0.
  \label{eq:anticomm}
\end{equation}
This algebraic statement does two things at the same time. First, swapping two fermions gives a
minus sign, which is the antisymmetry of the wavefunction. Second, acting with $\cre{i}$ twice
on any state gives zero, which is the Pauli exclusion principle. In this course we will see three
types of local degree of freedom that are built in this way.
\begin{itemize}[nosep]
  \item \textbf{Spinful fermions.} Each site has four possible states, $\ket{0}$, $\ket{\up}$,
    $\ket{\dn}$ and $\ket{\up\dn}$. This is the realistic case, the one that we would use for a
    hydrogen atom.
  \item \textbf{Spinless fermions.} Each site has only two states, $\ket{0}$ and $\ket{1}$.
    Formally, a spinful fermion is the same as two decoupled spinless fermions, one per spin
    flavor.
  \item \textbf{Spin-$\tfrac12$ operators.} Again there are two states, $\ket{\up}$ and
    $\ket{\dn}$, but now the operators are \emph{bosonic}, meaning that they commute on different
    sites instead of anticommuting. As we will see in Section~\ref{sec:strongcoupling}, a local
    spin emerges from a spinful fermion once we project out double occupancy and the empty
    state. This is the origin of what is called spin-charge separation.
\end{itemize}

\subsection{The tight-binding dimer as a worked example}
\label{sec:dimer}
\subsubsection{Bonding and antibonding orbitals}
Before we add any interactions, let us solve the smallest possible chain by hand, since we will
come back to it many times. Let us take $L=2$ sites with hopping $t$, and let us include spin
from the start, so each site can hold a spin-up and a spin-down electron independently, and the
Hamiltonian reads
\begin{equation}
  \Ham_0 = -t \sum_\sigma \left(\cre{0\sigma}\ann{1\sigma} + \cre{1\sigma}\ann{0\sigma}\right).
\end{equation}
Spin never enters the hopping, so $\Ham_0$ splits into two identical $2\times2$ spinless
problems, one per spin flavor, and each of them reads
\begin{equation}
  \Ham_0^{(\sigma)} = -t\begin{pmatrix} 0 & 1 \\ 1 & 0\end{pmatrix}
  \;\Longrightarrow\;
  \varepsilon_{\pm} = \mp t, \qquad
  \ket{\pm} = \frac{1}{\sqrt2}\left(\ket{0} \pm \ket{1}\right).
\end{equation}
The state $\ket{+}$, at energy $-t$, is called the \textbf{bonding} orbital, and $\ket{-}$, at
energy $+t$, is called the \textbf{antibonding} orbital. Now let us restore spin. Each of these
two orbital levels can hold a spin-up and a spin-down electron, so we have $2\times 2 = 4$
single-particle eigenstates in total, even though there are only \emph{two} different energies,
$\pm t$, each of them doubly degenerate. This answers a question that you may have already asked
yourself while looking at the notebook, which is why there are four eigenstates for two sites
and why some of them are degenerate. The degeneracy counts spin, not orbital content, and it
comes from the fact that $\Ham_0$ commutes with the total spin, since nothing in $\Ham_0$
distinguishes $\up$ from $\dn$.

\subsubsection{The two-electron many-body basis}
If we fill in electrons one at a time starting from $\ket{\Omega}$, we generate the full
many-body basis for two spinful sites, as we set up in the previous section. At half filling with
two electrons, for instance, there are $\binom{4}{2}=6$ states in total. Four of them are singly
occupied, with one electron per site ($\up\dn$, $\dn\up$, $\up\up$, $\dn\dn$), and two of them
are doubly occupied, with both electrons on the same site. We should keep this counting in mind,
since it is what we will use in Section~\ref{sec:strongcoupling} to build the effective spin
model at strong coupling.

\subsection{Two microscopic interactions, two broken symmetries}
Equation~\eqref{eq:generalH} is completely general, so in practice we have to choose a concrete
form for $V_{ijkl}$ and ask which symmetry-broken state it favors in the thermodynamic limit,
$L\to\infty$. We will focus on two of the simplest choices, which are also well motivated
physically.

\subsubsection{The Hubbard model of spinful fermions}
Let us keep only the interaction between
opposite spins on the \emph{same} site, which gives
\begin{equation}
  \Ham_{\mathrm{Hub}} = -\sum_{ij,\sigma} t_{ij}\, \cre{i\sigma}\ann{j\sigma}
    + U \sum_i n_{i\up} n_{i\dn}, \qquad n_{i\sigma} \equiv \cre{i\sigma}\ann{i\sigma}.
  \label{eq:hubbard}
\end{equation}
Physically, this local repulsion is what the onsite electrostatic Coulomb interaction becomes
once screening is included, and it is the minimal Hamiltonian we need for \textbf{magnetism}.
Magnetic order breaks time-reversal and spin-rotational symmetry. The exact Hamiltonian is
invariant under any spin rotation but its ground state is not, and if we apply time reversal to
the ground state we get a different state with the opposite magnetization.

\subsubsection{The spinless nearest-neighbor model}
Now let us remove the spin degree of freedom and
keep instead a density--density repulsion between neighboring sites,
\begin{equation}
  \Ham_{\mathrm{CDW}} = -t\sum_i \left(\cre{i}\ann{i+1} + \mathrm{h.c.}\right)
    + V \sum_i n_i n_{i+1}, \qquad n_i \equiv \cre{i}\ann{i},
  \label{eq:cdwmodel}
\end{equation}
which is what we would get from a longer-range electrostatic repulsion once we truncate it to
nearest neighbors. This is the minimal Hamiltonian for a \textbf{charge density wave (CDW)}.
Here the broken symmetry is the \emph{translational} symmetry of the lattice, and charge piles up
on one sublattice while it is depleted on the other.

Note that the two models live on the same chain and differ only in what the interaction
penalizes, which is two electrons on one site in the first case and two electrons on neighboring
sites in the second. As a result, they differ in what orders, which is the spin in the first case
and the charge in the second. Figure~\ref{fig:two-interactions} shows the two side by side.

\begin{figure}[H]
  \centering
  \includegraphics[width=\textwidth]{figures/classical_magnetism/two_interactions.pdf}
  \caption{The two interactions of this section and the order that each one favors. (a) In the
    Hubbard model of Eq.~\eqref{eq:hubbard}, an up and a down electron on the same site cost $U$,
    so at half filling the electrons spread out with one per site and their spins align
    antiparallel from site to site, which is the antiferromagnet. (b) In the spinless model of
    Eq.~\eqref{eq:cdwmodel}, two electrons on neighboring sites cost $V$, so the charge piles up
    on every other site, which we draw as the height of a column, and the sites in between are
    left nearly empty, which is the charge density wave.}
  \label{fig:two-interactions}
\end{figure}

\subsubsection{Where do $U$ and $V$ come from physically?}
We will treat $U$ and $V$ as given parameters for the rest of the course, but let us stop for a
moment on where they come from, because this also explains why both repulsive and attractive
effective interactions are physically reasonable.
\begin{itemize}[nosep]
  \item \textbf{Direct electrostatics.} The screened Coulomb repulsion between electrons is
    always present, and it is always repulsive. Its onsite part gives us $U$, and its
    longer-range part, truncated to nearest neighbors, gives us $V$.
  \item \textbf{Quasiparticle-mediated interactions.} Let us take some other bosonic degree of
    freedom that couples to the electron density or spin, such as lattice vibrations, which are
    phonons, collective spin fluctuations, which are magnons, or collective charge fluctuations,
    which are plasmons and excitons. If we integrate it out, we generate an \emph{effective}
    quartic interaction of exactly the same form as Eq.~\eqref{eq:generalH}, even though there
    was no bare electron--electron term at the start.
\end{itemize}
The interaction that we see in the end is the sum of all these contributions, and depending on
which mechanism wins it can be repulsive or \emph{attractive} in total. In this course we work
with repulsive $U, V > 0$, which is the regime relevant for magnetism and CDW order. Attractive
interactions instead favor Cooper pairing and superconductivity, a case that we will not study
here, although it uses the same formal tools.

\subsection{Mean-field theory}
\subsubsection{A single-particle approximation}
Solving Eq.~\eqref{eq:hubbard} exactly means working in a Hilbert space of dimension $4^L$, or
$2^L$ per spin species, which is exponential in the system size. So the question we want to ask
is not how to solve it exactly, but how to solve it approximately. Is there some single-particle
Hamiltonian $\HMF$ whose ground state is close to the true ground state of $\Ham$? Finding this
Hamiltonian is the main task of mean-field theory.

\subsubsection{Decoupling the interaction}
The simplest way to do this is to write each quartic term as a product of two bilinears and to
replace one of the bilinears by its expectation value. We drop the fluctuation term that is left.
This is exact only at $U=0$, but we will see that it can still be a very good approximation away
from this limit. The decoupling then reads
\begin{equation}
  n_{i\up} n_{i\dn} \;\longrightarrow\; \expval{n_{i\up}} n_{i\dn} + n_{i\up}\expval{n_{i\dn}}
    - \expval{n_{i\up}}\expval{n_{i\dn}}.
\end{equation}
If we define the local magnetization as $m_i \equiv \expval{n_{i\up}} - \expval{n_{i\dn}}$, the
Hubbard interaction becomes an effective, spin-dependent onsite potential,
\begin{equation}
  \HMF = -\sum_{ij,\sigma} t_{ij}\,\cre{i\sigma}\ann{j\sigma}
    - \frac{U}{2}\sum_i m_i\, \sigma_z + \mathrm{const.}
  \label{eq:mfham}
\end{equation}
where $\sigma_z=\pm1$ for $\sigma=\up,\dn$, so the onsite term reads $-\tfrac U2 m_i\sigma$ site by
site. As a result, spin-up electrons now see a shifted onsite energy $-Um_i/2$, and spin-down
electrons see $+Um_i/2$. This splitting is generated entirely by the interaction, and it is what
is called the \textbf{exchange splitting}. More generally, if we also keep expectation values such
as $\expval{\cre{i\up}\ann{i\dn}}$, $\HMF$ can describe non-collinear magnetization, with
components $m_i^x \equiv 2\Re\expval{\cre{i\up}\ann{i\dn}}$, $m_i^y \equiv
2\Im\expval{\cre{i\up}\ann{i\dn}}$, and $m_i^z\equiv m_i$, so in principle mean-field theory can
capture ferromagnets, antiferromagnets, spin spirals and even skyrmion textures.

\subsubsection{The self-consistency loop in practice}
Concretely, the procedure that we follow has
four steps.
\begin{enumerate}[nosep]
  \item Guess an initial value for the local order parameters, for example $m_i^{(0)}$ for
    magnetism or $\expval{n_i}^{(0)}$ for a CDW.
  \item Build $\HMF$ from Eq.~\eqref{eq:mfham} using this guess, and diagonalize it.
  \item Fill the lowest single-particle orbitals up to the target electron number, and
    recompute $m_i$, or $\expval{n_i}$, from the newly occupied orbitals.
  \item Compare the new order parameters to the previous ones. If they have not changed within
    some tolerance, we are done, and this is the self-consistent solution. Otherwise, mix the old
    and new guesses and go back to step 2.
\end{enumerate}
Figure~\ref{fig:scf-loop} draws these four steps as a loop, each one on a chain of four sites.
Since this is a nonlinear fixed-point problem, it can converge to different fixed points
depending on where we start it, and this is the dependence on the initial guess that we come
back to below.

\subsubsection{Mean-field theory as a variational method}
\label{sec:variational}
There is an equivalent way to think about all of this, and in some sense a more useful one. Let
us restrict the many-body ground state to be a single Slater determinant, $\ket{\Psi} =
\cre{a_1}\cre{a_2}\cdots\vac$, and minimize $\expval{\Ham}$ over the choice of single-particle
orbitals $\{a_n\}$. Since $\HMF$ depends on $\expval{n_{i\sigma}}$, and $\expval{n_{i\sigma}}$
itself depends on the ground state of $\HMF$, minimizing the energy in this way is the same as
the self-consistency loop we just described. We guess $\{m_i\}$, diagonalize $\HMF$, recompute
$\{m_i\}$ from the filled orbitals, and repeat until it converges. So mean-field theory is the
best approximation we can build out of \emph{product states}, and this restriction to product
states is what will give us problems in Section~\ref{sec:breakdown}.

\subsubsection{Gap opening at half filling}
Let us now force half filling and double the unit cell, so we have two sites with alternating
majority spin. At $U=0$ this only folds the metallic cosine band onto itself. Once $U>0$, the
self-consistent solution opens a gap between the occupied and empty bands, and this gap grows
with $U$ and becomes linear, $\Delta \sim U$, once $U \gg t$. If we look at the single-particle
spectral function instead of the eigenvalues, we see the same behavior, since the continuous
metallic density of states at $U=0$ develops a clean gap that becomes wider with $U$, and this is
what a spectroscopy experiment would measure.

\subsubsection{Multiple self-consistent solutions and their energetics}
Since the self-consistency loop is a \emph{nonlinear} fixed-point problem, the solution it
converges to depends on where we start it. A ferromagnetic initial guess converges to a
metallic, ferromagnetic solution, while an antiferromagnetic initial guess converges to an
insulating, antiferromagnetic solution. Both of them are legitimate stationary points of the
mean-field energy, but only one of them is the true mean-field ground state with the lowest
energy. If we take a half-filled chain with only nearest-neighbor hopping, the antiferromagnetic
solution is always lower in energy, and the gap between the two scales as
\begin{equation}
  E_{\mathrm{FM}} - E_{\mathrm{AFM}} \;\sim\; \frac{1}{U} \xrightarrow{U\to\infty} 0.
\end{equation}
So the two solutions only become degenerate in the strict atomic limit $U\to\infty$, and at any
finite $U$ they are physically different states, one metallic and one insulating. Panel (b) of
Figure~\ref{fig:scf-loop} draws this as an energy landscape with two valleys, and a run that
starts on the ferromagnetic side stays in the higher one.

\subsection{From electrons to spins at strong coupling}
\label{sec:strongcoupling}
\subsubsection{Saturation of the local moment}
As $U/t \to \infty$, the local moment $\expval{n_{i\up}} -
\expval{n_{i\dn}}$ saturates in magnitude to $1$ on every site. Double occupancy and empty sites
become forbidden in energy, and every site ends up with exactly one localized electron. In this
regime the physics is better described by \emph{spins} than by itinerant fermions, and let us now
see in detail why.

\subsubsection{The Hubbard dimer and its low-energy manifold}
Let us take our two-site dimer again, with hopping $t$, interaction $U$ and two electrons in
total, so we are at half filling. We already counted a six-dimensional many-body basis for this
problem in Section~\ref{sec:dimer}. For $U \gg t$, this basis splits into two groups.
\begin{itemize}[nosep]
  \item A four-dimensional \textbf{ground-state manifold} of singly occupied configurations,
    which are $\up\dn$, $\dn\up$, $\up\up$ and $\dn\dn$ across the two sites, at energy $\sim 0$.
  \item A \textbf{virtual manifold} of doubly occupied configurations, at high energy, $\sim U$.
\end{itemize}
Let us look closely at the ground-state manifold. It is the Hilbert space of two
spin-$\tfrac12$ degrees of freedom. In other words, our strongly interacting electronic problem
has become a spin problem. Panel (c) of Figure~\ref{fig:superexchange} draws the six states with
their energies.

\subsubsection{Superexchange and the coupling $J = 4t^2/U$}
The only term that connects the two manifolds is the hopping $t$. Since nothing in
$\Ham_{\mathrm{Hub}}$ breaks spin rotation, symmetry alone already tells us that the effective
low-energy Hamiltonian has to be proportional to $\vb S_1\cdot\vb S_2$ at leading order in spin
operators. To find the coefficient, we take $\Ham_U = U\sum_i n_{i\up}n_{i\dn}$ as
the unperturbed Hamiltonian, with the singly and doubly occupied configurations of
Section~\ref{sec:dimer} as its eigenstates, and the hopping $V =
-t\sum_\sigma(\cre{0\sigma}\ann{1\sigma}+\mathrm{h.c.})$ as the perturbation. The parallel
configurations $\ket{\up\up}$ and $\ket{\dn\dn}$ have no doubly occupied virtual state to hop
into, since Pauli exclusion blocks it, so they are already exact eigenstates and are not shifted
at any order. This is our triplet, at $E_{\mathrm{triplet}}=0$. Panel (a) of
Figure~\ref{fig:superexchange} draws this blocked hop, and panel (b) the hop that is allowed when
the spins are antiparallel.

\begin{figure}[H]
  \centering
  \includegraphics[width=\textwidth]{figures/classical_magnetism/superexchange.pdf}
  \caption{The two spin channels of the half-filled Hubbard dimer at strong coupling, which is
    where the $J=4t^2/U$ of Eq.~\eqref{eq:superexchange} comes from. (a) With parallel spins there
    is no doubly occupied state to hop into, since Pauli exclusion blocks the process completely,
    and the triplet stays exactly at $E_{\mathrm{triplet}}=0$ at every order. (b) With antiparallel
    spins either electron can hop onto its neighbor, passing through a virtual doubly occupied
    configuration at energy $U$ and ending in the exchanged configuration. Each hop has a matrix
    element $-t$ and the virtual state gives an energy denominator $-U$, so second-order
    perturbation theory lowers the antiparallel channel by an amount of order $t^2/U$ and leaves
    the parallel one unchanged. (c) All six two-electron states of the dimer as levels. The four
    with one electron per site are at $E=0$ and form the ground-state manifold, which is the
    Hilbert space of two spins, and the two doubly occupied states are raised by $U$, and the
    hops of (b) visit them only virtually.}
  \label{fig:superexchange}
\end{figure}

The antiparallel configurations are more subtle, since \emph{either} electron can hop. Each one
of $\ket{\up\dn} = \cre{0\up}\cre{1\dn}\vac$ and $\ket{\dn\up} = \cre{0\dn}\cre{1\up}\vac$ connects
through $V$ to \emph{both} virtual doubly occupied states, $\ket{2,0} = \cre{0\up}\cre{0\dn}\vac$
and $\ket{0,2} = \cre{1\up}\cre{1\dn}\vac$, which are at energy $U$ above the low-energy
manifold. The matrix elements are $\bra{2,0}V\ket{\up\dn} = -t$ and $\bra{0,2}V\ket{\up\dn}=-t$,
and by the site-exchange symmetry of the problem we also have $\bra{2,0}V\ket{\dn\up} = +t$ and
$\bra{0,2}V\ket{\dn\up}=+t$, where the sign flips because of fermionic anticommutation once the
two electrons are reordered onto the same site. Only the total spin is conserved here, not the
sublattice, so the clean way to organize the calculation is to work directly in the singlet and
triplet basis rather than in $\{\ket{\up\dn},\ket{\dn\up}\}$. Only the singlet combination
$\ket{s}=\tfrac1{\sqrt2}(\ket{\up\dn}-\ket{\dn\up})$ has any overlap with the doubly occupied
states, because the matrix elements of the triplet combination to $\ket{2,0}$ and $\ket{0,2}$
cancel by the sign flip above. By the same site-exchange symmetry, only the symmetric combination
$\ket{d}=\tfrac1{\sqrt2}(\ket{2,0}+\ket{0,2})$ couples back to it, since the antisymmetric
combination $\tfrac1{\sqrt2}(\ket{2,0}-\ket{0,2})$ is odd under the mirror and $\ket s$ is even
under it. Explicitly, we have
\begin{equation}
  \bra{d}V\ket{s} = \tfrac1{\sqrt2}\left[\bra{2,0}V\ket{\up\dn}-\bra{2,0}V\ket{\dn\up}
    +\bra{0,2}V\ket{\up\dn}-\bra{0,2}V\ket{\dn\up}\right]\tfrac1{\sqrt2}
  = \tfrac12\left[-t-t-t-t\right] = -2t,
\end{equation}
so the singlet sector reduces to an exact $2\times2$ problem, with $\ket s$ at energy $0$ coupled
to $\ket d$ at energy $U$ by the matrix element $-2t$. The orthogonal antisymmetric doubly
occupied combination is decoupled and remains an exact eigenstate at energy $U$. Standard
non-degenerate second-order perturbation theory on this $2\times2$ block, in the form of
Schrieffer--Wolff or equivalently L\"owdin, gives
\begin{equation}
  E_{\mathrm{singlet}} \approx 0 + \frac{|\bra{d}V\ket s|^2}{0-U} = -\frac{4t^2}{U},
\end{equation}
which one can check is exactly the $U\gg t$ expansion of the closed-form eigenvalue of the full
$2\times2$ matrix, $E_-=\tfrac U2-\sqrt{(U/2)^2+4t^2}\to-4t^2/U$. A full numerical exact
diagonalization of the two-site, two-electron Hubbard model confirms both this asymptotic value
and the exact triplet energy $E_{\mathrm{triplet}}=0$ at every $U/t$, not only at strong
coupling. Let us compare this to the exact spectrum of $J\,\vb S_1\cdot\vb S_2$ itself. Writing
$\vb S_{\mathrm{tot}}=\vb S_1+\vb S_2$ gives $\vb S_1\cdot\vb S_2 =
\tfrac12\left[S_{\mathrm{tot}}(S_{\mathrm{tot}}+1)-\tfrac34-\tfrac34\right]$, which is
$-\tfrac34$ for the singlet ($S_{\mathrm{tot}}=0$) and $+\tfrac14$ for the triplet
($S_{\mathrm{tot}}=1$), meaning that $E_{\mathrm{singlet}}=-\tfrac34J$ and
$E_{\mathrm{triplet}}=\tfrac14J$, with a gap of exactly $J$ between them. Matching this gap to the
one we just computed fixes
\begin{equation}
  J = E_{\mathrm{triplet}}-E_{\mathrm{singlet}} = \frac{4t^2}{U} \qquad\Longrightarrow\qquad
  \Ham_{\mathrm{eff}} = J\, \vb S_1\cdot\vb S_2,
  \label{eq:superexchange}
\end{equation}
which is the \textbf{antiferromagnetic superexchange} coupling. Intuitively, virtual hopping into
the doubly occupied states, which is blocked by Pauli exclusion for parallel spins, lowers the
energy of the singlet combination of antiparallel configurations. This is why the effective
low-energy interaction favors antialignment, even though the Hubbard repulsion itself has no
explicit spin dependence. The same argument holds without change on any lattice with hoppings
$t_{ij}$, so the half-filled, strongly interacting Hubbard model on \emph{any} lattice maps onto
a spin-$\tfrac12$ \textbf{Heisenberg model},
\begin{equation}
  \Ham_{\mathrm{Heis}} = \sum_{ij} J_{ij}\, \vb S_i \cdot \vb S_j, \qquad J_{ij} \sim
  \frac{t_{ij}^2}{U}.
  \label{eq:heislattice}
\end{equation}
with the same numerical prefactor as Eq.~\eqref{eq:superexchange}, $J_{ij}=4t_{ij}^2/U$, for each
bond treated in isolation in this way.
If instead we have more than one electron per site, as in multi-orbital atoms, we map onto
Heisenberg models with higher spin, which are spin-$1$ for two electrons per site,
spin-$\tfrac32$ for three, and so on. Additional weakly interacting orbitals can even flip the
\emph{sign} of $J_{ij}$ and give ferromagnetic rather than antiferromagnetic coupling, which is
why real materials are not always antiferromagnets.

\subsection{Classical magnetic order and frustration}
If we now treat the spins in $\Ham_{\mathrm{Heis}}$ as classical vectors, which is an
approximation very close in spirit to mean-field theory, finding the ground state becomes a
direct energy minimization.

\subsubsection{Bipartite lattices}
On the square and honeycomb lattices, we can always split the
sites into two sublattices $A, B$ such that every bond connects $A$ to $B$. For
antiferromagnetic $J>0$, the classical ground state is then $\vb S_A = -\vb S_B$, which is
collinear N\'eel order.

\subsubsection{Frustration}
The situation is more interesting on lattices that are \emph{not}
bipartite, such as the triangular and kagome lattices, which are built from triangles that share
corners or edges. On these lattices, no choice of two sublattices can satisfy every
antiferromagnetic bond at the same time. The classical ground state becomes instead
\textbf{non-collinear}, and neighboring spins rotate by $120^\circ$ as we go around each
triangle, which gives a spiral magnetic order with a magnetic unit cell of several sites.
Figure~\ref{fig:neel-vs-spiral} draws the N\'eel state, a single frustrated triangle and the
$120^\circ$ order side by side.

\begin{figure}[H]
  \centering
  \includegraphics[width=\textwidth]{figures/classical_magnetism/neel_vs_spiral.pdf}
  \caption{Classical ground states of the Heisenberg model of Eq.~\eqref{eq:heislattice} with
    antiferromagnetic $J>0$, obtained by treating every spin as a classical vector. (a) On a
    bipartite lattice every bond connects the two sublattices, so $\vb S_A = -\vb S_B$ satisfies
    all of them at the same time and the order is collinear N\'eel. (b) A single triangle is
    where this fails. Once two spins are antiparallel and satisfy their bond, the third spin
    cannot be antiparallel to both, which we draw as two ghost arrows, so one bond is left

    edge-sharing triangles and no two-sublattice assignment can satisfy all of them, so the
    configuration with minimum energy is instead the non-collinear $120^\circ$ spiral, with a

    sublattices is up or down.}
  \label{fig:neel-vs-spiral}
\end{figure}

\subsubsection{Anisotropic exchange}
Real materials often break the SU(2) spin-rotation symmetry of
$\Ham_{\mathrm{Heis}}$ through spin--orbit coupling, which adds terms bilinear in spin that are
\emph{not} symmetric under a common rotation of all spins. Three of them appear often enough to
have their own names.
\begin{itemize}[nosep]
  \item \textbf{Antisymmetric exchange}, also called \textbf{Dzyaloshinskii--Moriya exchange},
    $\vb D_{ij}\cdot(\vb S_i\times
    \vb S_j)$, which appears when mirror symmetry is broken. It favors spins at
    $90^\circ$ to each other, meaning non-collinear order even without any geometric frustration.
  \item \textbf{Ising anisotropy}, coupling only $S_i^z S_j^z$, which comes from strong
    spin--orbit coupling and single-ion anisotropy and pushes the spins toward classical
    behavior, restricted to a single axis or plane.
  \item \textbf{Kitaev exchange}, a \emph{bond-dependent} Ising-like coupling where $x$-bonds
    couple $S^xS^x$, $y$-bonds couple $S^yS^y$ and $z$-bonds couple $S^zS^z$. On the honeycomb
    lattice, for example, no single spin configuration can satisfy the three bond types at the
    same time, which is why this term is intrinsically frustrating and a key ingredient of
    quantum spin liquid models.
\end{itemize}
We will not compute with any of these three terms in this course, but they are what we use as
soon as spin-orbit coupling is strong, and they are behind most of the exotic magnets and
quantum spin liquid candidates that are studied today.

\subsection{Charge density waves as a mean-field problem}
\subsubsection{Mean-field decoupling of the spinless model}
The same tools apply to $\Ham_{\mathrm{CDW}}$ from Eq.~\eqref{eq:cdwmodel}. We decouple the
density--density term as $\expval{n_i} n_{i+1} + n_i\expval{n_{i+1}} -
\expval{n_i}\expval{n_{i+1}}$ and iterate to self-consistency, as before. At $V=0$ the
chain is a featureless, half-filled metal with $n_i = \tfrac12$ on every site. As we turn on $V$,
we get the same qualitative evolution of the spectrum as in the Hubbard case, where a gap opens
and grows as $\sim V$ at large $V$.

\subsubsection{The charge imbalance as order parameter}
What changes is the order parameter, which is now the
\textbf{charge imbalance},
\begin{equation}
  \delta n \equiv n_{\text{even}} - n_{\text{odd}},
\end{equation}
and it grows from $0$ at $V=0$ toward $\delta n \to 1$ at large $V$, meaning that the sites end
up alternating between fully filled and fully empty. The broken symmetry here is translational
rather than time-reversal, but note how closely the mechanism, and even the shape of the
evolution of the spectrum, follows the magnetic case.

\subsection{Where mean-field theory breaks down}
\label{sec:breakdown}
So far mean-field theory has worked well every time, and the reason is that it is a very good
technique when the true ground state \emph{does} spontaneously break a symmetry. But nothing
guarantees this in advance, and the Hubbard dimer at half filling gives us a clean
counterexample.

\subsubsection{The mean-field solution of the dimer}
The exact Hamiltonian $\Ham_{\mathrm{Hub}}$ for two sites is fully symmetric under spin rotation
and time reversal. Its mean-field decoupling, however, is only self-consistent with a
\emph{symmetry-breaking} ansatz once $U$ passes a threshold. Below the threshold, $\HMF$ stays
non-magnetic, and above it, the converged solution has finite local moments of opposite sign on
the two sites, which eventually saturate, as in the regime we studied in
Section~\ref{sec:strongcoupling}. The mean-field gap follows this transition too, since it stays
constant below the threshold and then grows linearly above it.

\subsubsection{The exact singlet ground state}
Let us now compare this to the \emph{exact} many-body ground state, which looks quite different.
In the strongly interacting limit, Section~\ref{sec:strongcoupling} already told us that the
dimer maps onto $\Ham_{\mathrm{eff}} = J\,\vb S_1\cdot\vb S_2$, and we can diagonalize this by
hand. Its exact ground state is the singlet
\begin{equation}
  \ket{\Psi_{\mathrm{singlet}}} = \frac{1}{\sqrt2}\Big(\ket{\up\dn} - \ket{\dn\up}\Big).
\end{equation}
This state has $\expval{S_1^z} = \expval{S_2^z} = 0$. It does not break time-reversal symmetry,
in direct contradiction with what the symmetry-broken mean-field solution told us to expect. The
reason is structural and not a numerical accident. The state $\ket{\Psi_{\mathrm{singlet}}}$ is an
entangled superposition, and it cannot be written as a single Slater determinant, for any choice
of orbitals or spin quantization axis. Mean-field theory is built by construction from product
states, as we saw in Section~\ref{sec:variational}, so it can never reach this state.

\subsubsection{Why this matters}
The Hubbard dimer is the smallest Hamiltonian that shows this kind
of failure, but the failure itself is completely generic. Whenever the true many-body ground
state is entangled and not adiabatically connected to a product state, mean-field theory gets the
physics qualitatively wrong, with the wrong symmetry, the wrong order, and sometimes a completely
wrong phase. This defines the plan for the rest of the course. \emph{Exact diagonalization}, in
Sessions 2 and 3, solves small many-body Hamiltonians with no product-state restriction at all,
and \emph{tensor network} methods, in Sessions 4 and 5, allow us to recover the exact answer at
system sizes where exact diagonalization is no longer possible.

\subsection*{Closing summary}
\begin{itemize}[nosep]
  \item Second quantization allows us to write single-particle and many-body ($\Order{4}$-fermion)
    Hamiltonians in the same language, and the interaction term is what drives all correlated
    physics.
  \item Mean-field theory decouples the interaction into an effective single-particle problem
    that we solve self-consistently. Equivalently, it is a variational search over Slater
    determinants.
  \item The Hubbard model gives us magnetism, which breaks time-reversal and spin symmetry, and
    the spinless nearest-neighbor model gives us charge density waves, which break translational
    symmetry. Both come from essentially the same mean-field mechanism.
  \item In the strongly interacting limit, second-order perturbation theory maps the Hubbard
    model onto a Heisenberg spin model with $J\sim t^2/U$, which is the superexchange coupling.
    Classically this model shows collinear order on bipartite lattices and non-collinear,
    frustrated order on other lattices.
  \item Mean-field theory can fail qualitatively whenever the true ground state is entangled
    beyond any product state, as we saw for the singlet ground state of the Hubbard dimer. This
    failure is what motivates exact diagonalization and tensor networks, which we start in the
    next session.
\end{itemize}
